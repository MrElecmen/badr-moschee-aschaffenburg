# Badr Moschee Aschaffenburg – Website

Statische Website aus reinem **HTML und CSS** (kein JavaScript, keine externen Schriften oder Tracker – DSGVO-freundlich).

## Dateien
- `index.html` – Startseite (Gebetszeiten, Über uns, Angebote, Termine, Spenden, Kontakt)
- `impressum.html`, `datenschutz.html` – Pflichtseiten
- `style.css` – gesamtes Design (responsive, mit mobilem Menü ohne JavaScript)

## Vor der Veröffentlichung anpassen
Alle Platzhalter in `[eckigen Klammern]` sowie folgende Angaben ersetzen:
- Adresse, Telefonnummer, E-Mail-Adresse
- Bankverbindung (IBAN/BIC, Vereinsname)
- Gebetszeiten und Termine
- Impressum (Vorstand, Vereinsregisternummer) und Datenschutzerklärung prüfen lassen

## Ansehen
`index.html` einfach im Browser öffnen. Zum Veröffentlichen alle Dateien auf einen Webspace hochladen
(oder kostenlos über GitHub Pages).
